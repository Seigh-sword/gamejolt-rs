# Code of Conduct

## Our standard

We want participation in this project to be respectful, constructive, and
welcoming to people with different backgrounds and experience levels.

Examples of helpful behavior include:

- Communicating with respect and assuming good intent.
- Giving actionable, technical feedback focused on the work.
- Accepting corrections and differing technical perspectives gracefully.
- Helping make project discussions accessible to newcomers.

Unacceptable behavior includes harassment, discriminatory language, personal
attacks, threats, deliberate disruption, and publishing another person's
private information without permission.

## Scope

This code of conduct applies to project spaces, including issues, pull
requests, discussions, and other interactions representing the project.

## Reporting

Report conduct concerns privately to the project maintainers through the
contact information on the GitHub organization or repository profile. Include
relevant context and links where possible. Do not post sensitive details
publicly.

Maintainers will review reports as promptly and fairly as possible and may
remove content, restrict participation, or take other proportionate action.
Retaliation against someone who raises a concern in good faith is not
acceptable.

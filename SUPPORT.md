# Support

## Before asking

- Read the [quickstart](docs/quickstart.md), [API reference](docs/api-reference.md),
  and [feature status](docs/features.md).
- Confirm the required Cargo feature is enabled.
- Try the latest compatible crate release and stable Rust toolchain.
- Reduce the problem to a short example and a redacted error.

## Where to ask

Use GitHub Issues for reproducible bugs and scoped feature requests. Choose the
matching issue template.

For general usage questions, start a GitHub Discussion if Discussions are
enabled for the repository. Otherwise, use the repository's documented
maintainer contact.

Do not use public issues for security vulnerabilities. Follow
[SECURITY.md](SECURITY.md).

## Include in a report

Include the crate version, Rust version, target, enabled features, expected
behavior, observed behavior, and relevant redacted output.

Never post private keys, user tokens, signed URLs, private player data, or
unredacted request logs.

Community support is provided on a best-effort basis. There is no guaranteed
response time or paid support commitment.
